Graphs

Maps, social networks, the web, course prerequisites, package dependencies, mazes — all graphs. Trees, grids and linked lists are graphs too. Master BFS, DFS and a handful of classic algorithms, learn to recognise the graph hidden in a problem, and you can solve a huge family of questions.

01 The basics

Vocabulary

  • Vertex (node) and edge (a connection between two vertices). V = number of vertices, E = edges.
  • Directed (one-way, A → B) vs undirected (two-way, A — B).
  • Weighted: each edge has a cost, distance or capacity.
  • Degree: number of edges at a vertex (in-degree / out-degree when directed).
  • Path, cycle (a path back to its start), connected component (a maximal group of mutually reachable vertices).

Special graphs you’ll meet

  • Tree: connected, undirected, no cycles — exactly V − 1 edges.
  • DAG: directed acyclic graph — tasks with prerequisites; has a topological order.
  • Grid: each cell is a vertex, neighbours are edges (islands, mazes, flood fill).
  • Bipartite: vertices split into two groups with edges only between groups (2-colourable).
  • Implicit graph: vertices are states (words, lock combinations, board positions) generated on the fly.

03 BFS & DFS

Both visit every reachable vertex once in O(V + E). The difference is the order: BFS goes out in rings (queue), DFS goes deep first (stack / recursion). Always mark visited — unlike trees, graphs have cycles.

BFS — shortest path in an unweighted graph

Mark a vertex visited when you enqueue it (not when you dequeue it), or it can be added many times.

vector<int> bfs(vector<vector<int>>& adj, int src) {
    vector<int> dist(adj.size(), -1);       // -1 = not visited
    queue<int> q;
    dist[src] = 0; q.push(src);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u])
            if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); }
    }
    return dist;                            // fewest edges from src
}
int[] bfs(List<List<Integer>> adj, int src) {
    int[] dist = new int[adj.size()];
    Arrays.fill(dist, -1);                  // -1 = not visited
    Queue<Integer> q = new ArrayDeque<>();
    dist[src] = 0; q.offer(src);
    while (!q.isEmpty()) {
        int u = q.poll();
        for (int v : adj.get(u))
            if (dist[v] == -1) { dist[v] = dist[u] + 1; q.offer(v); }
    }
    return dist;                            // fewest edges from src
}
function bfs(adj, src) {
    const dist = new Array(adj.length).fill(-1);   // -1 = not visited
    const q = [src];
    dist[src] = 0;
    for (let head = 0; head < q.length; head++) {  // head index: no shift()
        const u = q[head];
        for (const v of adj[u])
            if (dist[v] === -1) { dist[v] = dist[u] + 1; q.push(v); }
    }
    return dist;                                   // fewest edges from src
}

DFS — explore, count components, detect cycles

Recursive DFS is short; for very deep graphs use an explicit stack to avoid stack overflow.

void dfs(vector<vector<int>>& adj, int u, vector<bool>& seen) {
    seen[u] = true;
    for (int v : adj[u])
        if (!seen[v]) dfs(adj, v, seen);
}
int countComponents(vector<vector<int>>& adj) {
    vector<bool> seen(adj.size(), false);
    int comps = 0;
    for (int u = 0; u < adj.size(); u++)
        if (!seen[u]) { comps++; dfs(adj, u, seen); }
    return comps;
}
void dfs(List<List<Integer>> adj, int u, boolean[] seen) {
    seen[u] = true;
    for (int v : adj.get(u))
        if (!seen[v]) dfs(adj, v, seen);
}
int countComponents(List<List<Integer>> adj) {
    boolean[] seen = new boolean[adj.size()];
    int comps = 0;
    for (int u = 0; u < adj.size(); u++)
        if (!seen[u]) { comps++; dfs(adj, u, seen); }
    return comps;
}
function countComponents(adj) {
    const seen = new Array(adj.length).fill(false);
    let comps = 0;
    for (let s = 0; s < adj.length; s++) {
        if (seen[s]) continue;
        comps++;
        const stack = [s];                  // iterative DFS
        seen[s] = true;
        while (stack.length) {
            const u = stack.pop();
            for (const v of adj[u])
                if (!seen[v]) { seen[v] = true; stack.push(v); }
        }
    }
    return comps;
}

04 The classic algorithms

Topological sort (Kahn’s algorithm)

Order a DAG so every edge points forward. Repeatedly take a vertex with in-degree 0. If some vertices are never taken, there’s a cycle.

vector<int> topoSort(int n, vector<vector<int>>& adj) {   // directed
    vector<int> indeg(n, 0), order;
    for (int u = 0; u < n; u++) for (int v : adj[u]) indeg[v]++;
    queue<int> q;
    for (int u = 0; u < n; u++) if (indeg[u] == 0) q.push(u);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (int v : adj[u]) if (--indeg[v] == 0) q.push(v);
    }
    return order.size() == n ? order : vector<int>{};   // empty = cycle
}
int[] topoSort(int n, List<List<Integer>> adj) {      // directed
    int[] indeg = new int[n], order = new int[n];
    for (int u = 0; u < n; u++) for (int v : adj.get(u)) indeg[v]++;
    Queue<Integer> q = new ArrayDeque<>();
    for (int u = 0; u < n; u++) if (indeg[u] == 0) q.offer(u);
    int k = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        order[k++] = u;
        for (int v : adj.get(u)) if (--indeg[v] == 0) q.offer(v);
    }
    return k == n ? order : new int[0];                // empty = cycle
}
function topoSort(n, adj) {                            // directed
    const indeg = new Array(n).fill(0), order = [];
    for (let u = 0; u < n; u++) for (const v of adj[u]) indeg[v]++;
    const q = [];
    for (let u = 0; u < n; u++) if (indeg[u] === 0) q.push(u);
    for (let head = 0; head < q.length; head++) {
        const u = q[head];
        order.push(u);
        for (const v of adj[u]) if (--indeg[v] === 0) q.push(v);
    }
    return order.length === n ? order : [];            // empty = cycle
}

Dijkstra — shortest paths with non-negative weights

Always settle the closest unsettled vertex (min-heap), then relax its edges. Skip stale heap entries. O((V + E) log V).

vector<long long> dijkstra(vector<vector<pair<int,int>>>& adj, int src) {
    vector<long long> dist(adj.size(), LLONG_MAX);
    priority_queue<pair<long long,int>, vector<pair<long long,int>>, greater<>> pq;
    dist[src] = 0; pq.push({0, src});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;                 // stale entry
        for (auto [v, w] : adj[u])
            if (d + w < dist[v]) { dist[v] = d + w; pq.push({dist[v], v}); }
    }
    return dist;
}
long[] dijkstra(List<List<int[]>> adj, int src) {
    long[] dist = new long[adj.size()];
    Arrays.fill(dist, Long.MAX_VALUE);
    PriorityQueue<long[]> pq = new PriorityQueue<>((a, b) -> Long.compare(a[0], b[0]));
    dist[src] = 0; pq.add(new long[]{0, src});
    while (!pq.isEmpty()) {
        long[] top = pq.poll();
        long d = top[0]; int u = (int) top[1];
        if (d > dist[u]) continue;                 // stale entry
        for (int[] e : adj.get(u))
            if (d + e[1] < dist[e[0]]) { dist[e[0]] = d + e[1]; pq.add(new long[]{dist[e[0]], e[0]}); }
    }
    return dist;
}
// JS has no built-in heap: a tiny binary heap of [dist, node] pairs
class PQ {
    constructor() { this.a = []; }
    get size() { return this.a.length; }
    push(x) {
        const a = this.a; a.push(x);
        for (let i = a.length - 1, p; i > 0 && a[p = (i - 1) >> 1][0] > a[i][0]; i = p) [a[p], a[i]] = [a[i], a[p]];
    }
    pop() {
        const a = this.a, top = a[0], last = a.pop();
        if (a.length) {
            a[0] = last;
            for (let i = 0; ; ) {
                const l = 2 * i + 1, r = l + 1;
                let m = i;
                if (l < a.length && a[l][0] < a[m][0]) m = l;
                if (r < a.length && a[r][0] < a[m][0]) m = r;
                if (m === i) break;
                [a[m], a[i]] = [a[i], a[m]]; i = m;
            }
        }
        return top;
    }
}
function dijkstra(adj, src) {                      // adj[u] = [[v, w], ...]
    const dist = new Array(adj.length).fill(Infinity), pq = new PQ();
    dist[src] = 0; pq.push([0, src]);
    while (pq.size) {
        const [d, u] = pq.pop();
        if (d > dist[u]) continue;                 // stale entry
        for (const [v, w] of adj[u])
            if (d + w < dist[v]) { dist[v] = d + w; pq.push([dist[v], v]); }
    }
    return dist;
}

Union-Find (Disjoint Set Union)

Merge groups and ask “same group?” in almost O(1). With path compression + union by size. Used for connectivity, cycle detection in undirected graphs, and Kruskal’s MST.

struct DSU {
    vector<int> parent, sz;
    DSU(int n) : parent(n), sz(n, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;                 // already connected
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a; sz[a] += sz[b];
        return true;
    }
};
class DSU {
    int[] parent, sz;
    DSU(int n) {
        parent = new int[n]; sz = new int[n];
        for (int i = 0; i < n; i++) { parent[i] = i; sz[i] = 1; }
    }
    int find(int x) { return parent[x] == x ? x : (parent[x] = find(parent[x])); }
    boolean unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;                 // already connected
        if (sz[a] < sz[b]) { int t = a; a = b; b = t; }
        parent[b] = a; sz[a] += sz[b];
        return true;
    }
}
class DSU {
    constructor(n) {
        this.parent = Array.from({ length: n }, (_, i) => i);
        this.sz = new Array(n).fill(1);
    }
    find(x) {
        while (this.parent[x] !== x) {
            this.parent[x] = this.parent[this.parent[x]];   // path halving
            x = this.parent[x];
        }
        return x;
    }
    unite(a, b) {
        a = this.find(a); b = this.find(b);
        if (a === b) return false;                // already connected
        if (this.sz[a] < this.sz[b]) [a, b] = [b, a];
        this.parent[b] = a; this.sz[a] += this.sz[b];
        return true;
    }
}

Cycle detection in a directed graph (3 colours)

White = unvisited, grey = on the current DFS path, black = finished. Reaching a grey vertex means a back edge → cycle.

bool hasCycle(int u, vector<vector<int>>& adj, vector<int>& color) {  // 0 white, 1 grey, 2 black
    color[u] = 1;
    for (int v : adj[u]) {
        if (color[v] == 1) return true;                     // back edge
        if (color[v] == 0 && hasCycle(v, adj, color)) return true;
    }
    color[u] = 2;
    return false;
}
boolean hasCycle(int u, List<List<Integer>> adj, int[] color) {  // 0 white, 1 grey, 2 black
    color[u] = 1;
    for (int v : adj.get(u)) {
        if (color[v] == 1) return true;                     // back edge
        if (color[v] == 0 && hasCycle(v, adj, color)) return true;
    }
    color[u] = 2;
    return false;
}
function hasCycle(u, adj, color) {                // 0 white, 1 grey, 2 black
    color[u] = 1;
    for (const v of adj[u]) {
        if (color[v] === 1) return true;          // back edge
        if (color[v] === 0 && hasCycle(v, adj, color)) return true;
    }
    color[u] = 2;
    return false;
}

07 Tips & tricks to learn it properly

🔎

Find the hidden graph

Ask: what are the vertices (cells, words, courses, states)? What makes an edge? Once named, pick an algorithm from the table.

✅

Mark visited on push

In BFS, mark when you enqueue. Marking when you dequeue lets the same vertex enter the queue many times.

🧱

Build the adjacency list first

Convert edge lists into adj before anything else, and decide directed vs undirected out loud.

🌊

Multi-source BFS

“Distance to the nearest X” for every cell → push all X into the queue at the start (rotting oranges, 01-matrix).

🔁

Reverse the problem

“Which cells can reach the ocean?” → BFS from the ocean. Surrounded regions → flood from the border.

📦

State = vertex

If the answer depends on more than position (keys held, stops used), put that into the visited key: (node, stops).

⚖️

Weights decide the tool

All weights equal → BFS. Non-negative → Dijkstra. Negative → Bellman–Ford. 0/1 weights → deque BFS.

🎨

Colours for directed cycles

Undirected cycle: visited neighbour that isn’t your parent. Directed cycle: grey (on-stack) neighbour.

🤝

Union-Find for “connect & ask”

Edges arrive one by one and you query connectivity? DSU beats re-running DFS each time.

🧮

Know your bounds

V ≤ 400 → O(V³) is fine. V up to 10⁵ → O(V + E) or O(E log V) only. Let constraints pick the algorithm.

📚

Recursion depth

A path of 10⁵ vertices overflows recursive DFS in Java/JS. Use an explicit stack or BFS when graphs can be long.

✏️

Draw it small

Sketch 5–6 vertices including a cycle and a disconnected piece. Trace visited/queue by hand once.

Common mistakes checklist

  • No visited set → infinite loop on cycles.
  • Forgetting the reverse edge for undirected graphs.
  • Only exploring from vertex 0 when the graph is disconnected.
  • Using DFS for shortest paths (it doesn’t give them).
  • Dijkstra with negative weights, or without skipping stale heap entries.
  • array.shift() in a JS BFS → O(V²).
  • Mixing 0-based and 1-based vertex labels from the input.
