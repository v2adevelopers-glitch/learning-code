Trees

File systems, the HTML DOM, databases, compilers and decision engines are all trees. In interviews, tree questions test one skill above all: recursion. Learn to think “what does my subtree need to tell me?” and most problems shrink to a few lines.

01 The basics

Vocabulary

  • Root: the top node (no parent). Leaf: a node with no children.
  • Parent / child / sibling — just like a family tree.
  • Depth of a node: edges from the root to it. Height of a tree: the longest root-to-leaf path.
  • Subtree: a node plus all its descendants — itself a tree. That’s why recursion fits so well.
  • A tree with n nodes has exactly n − 1 edges and no cycles.

Kinds of binary trees

  • Binary tree: every node has at most two children, left and right.
  • Full: every node has 0 or 2 children.
  • Complete: all levels full except possibly the last, filled left to right (heaps!).
  • Perfect: all leaves on the same level — 2h+1 − 1 nodes.
  • Balanced: left and right subtree heights differ by ≤ 1 everywhere → height O(log n).
  • BST: left subtree < node < right subtree, for every node.

02 Traversals

Depth-first (pre/in/post-order) uses recursion or a stack. Breadth-first (level order) uses a queue. The only difference between the three DFS orders is when you visit the node.

Pre / in / post-order (recursive)

Pre: node, left, right (copy a tree). In: left, node, right (BST → sorted). Post: left, right, node (delete a tree, compute heights).

void preorder(TreeNode* n, vector<int>& out) {
    if (!n) return;
    out.push_back(n->val);           // visit BEFORE children
    preorder(n->left, out);
    preorder(n->right, out);
}
void inorder(TreeNode* n, vector<int>& out) {
    if (!n) return;
    inorder(n->left, out);
    out.push_back(n->val);           // visit BETWEEN children
    inorder(n->right, out);
}
void postorder(TreeNode* n, vector<int>& out) {
    if (!n) return;
    postorder(n->left, out);
    postorder(n->right, out);
    out.push_back(n->val);           // visit AFTER children
}
void preorder(TreeNode n, List<Integer> out) {

Inorder with an explicit stack

Go left as far as possible pushing nodes; pop, visit, then move to the right child. Interviewers often ask for the iterative version.

vector<int> inorderIter(TreeNode* root) {
    vector<int> out;
    stack<TreeNode*> st;
    TreeNode* cur = root;
    while (cur || !st.empty()) {
        while (cur) { st.push(cur); cur = cur->left; }   // dive left
        cur = st.top(); st.pop();
        out.push_back(cur->val);                         // visit
        cur = cur->right;                                // then right subtree
    }
    return out;
}
List<Integer> inorderIter(TreeNode root) {
    List<Integer> out = new ArrayList<>();
    Deque<TreeNode> st = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !st.isEmpty()) {
        while (cur != null) { st.push(cur); cur = cur.left; }   // dive left
        cur = st.pop();
        out.add(cur.val);                                       // visit
        cur = cur.right;                                        // then right subtree
    }
    return out;
}
function inorderIter(root) {
    const out = [], st = [];
    let cur = root;
    while (cur || st.length) {
        while (cur) { st.push(cur); cur = cur.left; }    // dive left
        cur = st.pop();
        out.push(cur.val);                               // visit
        cur = cur.right;                                 // then right subtree
    }
    return out;
}

Level order (BFS)

Process the tree one level at a time with a queue. Snapshot the queue size to know where each level ends.

vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> res;
    if (!root) return res;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        vector<int> level;
        for (int sz = q.size(); sz > 0; sz--) {
            TreeNode* n = q.front(); q.pop();
            level.push_back(n->val);
            if (n->left) q.push(n->left);
            if (n->right) q.push(n->right);
        }
        res.push_back(level);
    }
    return res;
}
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        List<Integer> level = new ArrayList<>();
        for (int sz = q.size(); sz > 0; sz--) {
            TreeNode n = q.poll();
            level.add(n.val);
            if (n.left != null) q.offer(n.left);
            if (n.right != null) q.offer(n.right);
        }
        res.add(level);
    }
    return res;
}
function levelOrder(root) {
    const res = [];
    let level = root ? [root] : [];
    while (level.length) {                    // one array per level: no shift()
        res.push(level.map(n => n.val));
        const next = [];
        for (const n of level) {
            if (n.left) next.push(n.left);
            if (n.right) next.push(n.right);
        }
        level = next;
    }
    return res;
}

Height — the “return info up” template

Ask each child for its answer, combine, return. This shape solves height, diameter, balanced check, max path sum…

int height(TreeNode* n) {
    if (!n) return 0;                              // empty tree
    int l = height(n->left);                        // ask the children
    int r = height(n->right);
    return 1 + max(l, r);                          // combine
}
int height(TreeNode n) {
    if (n == null) return 0;                       // empty tree
    int l = height(n.left);                        // ask the children
    int r = height(n.right);
    return 1 + Math.max(l, r);                     // combine
}
function height(n) {
    if (!n) return 0;                              // empty tree
    const l = height(n.left);                      // ask the children
    const r = height(n.right);
    return 1 + Math.max(l, r);                     // combine
}

03 Binary search trees

The BST property

For every node: everything in its left subtree is smaller, everything in its right subtree is larger. So search, insert and delete each follow one path from the root — O(height).

  • Inorder traversal of a BST gives the values sorted.
  • Minimum = leftmost node, maximum = rightmost node.
  • Balanced (AVL, red-black: C++ std::map, Java TreeMap) → height O(log n).
OperationBalanced BSTSkewed BST
SearchO(log n)O(n)
InsertO(log n)O(n)
DeleteO(log n)O(n)
Min / maxO(log n)O(n)
Sorted outputO(n)O(n)

Inserting already-sorted values into a plain BST creates a “linked list” — try it in the playground below.

Search & insert

TreeNode* search(TreeNode* n, int x) {
    while (n && n->val != x)
        n = x < n->val ? n->left : n->right;     // go one way only
    return n;
}
TreeNode* insert(TreeNode* n, int x) {
    if (!n) return new TreeNode(x);              // found the empty spot
    if (x < n->val) n->left = insert(n->left, x);
    else if (x > n->val) n->right = insert(n->right, x);
    return n;                                    // duplicates ignored
}

Delete — three cases

Leaf: just remove it. One child: replace the node with that child. Two children: copy in the inorder successor (smallest value of the right subtree), then delete that successor.

TreeNode* remove(TreeNode* n, int x) {
    if (!n) return nullptr;
    if (x < n->val) n->left = remove(n->left, x);
    else if (x > n->val) n->right = remove(n->right, x);
    else {
        if (!n->left) return n->right;           // 0 or 1 child
        if (!n->right) return n->left;
        TreeNode* s = n->right;                  // 2 children:
        while (s->left) s = s->left;             //   inorder successor
        n->val = s->val;
        n->right = remove(n->right, s->val);
    }
    return n;
}
TreeNode remove(TreeNode n, int x) {
    if (n == null) return null;
    if (x < n.val) n.left = remove(n.left, x);
    else if (x > n.val) n.right = remove(n.right, x);
    else {
        if (n.left == null) return n.right;      // 0 or 1 child
        if (n.right == null) return n.left;
        TreeNode s = n.right;                    // 2 children:
        while (s.left != null) s = s.left;       //   inorder successor
        n.val = s.val;
        n.right = remove(n.right, s.val);
    }
    return n;
}
function remove(n, x) {
    if (!n) return null;
    if (x < n.val) n.left = remove(n.left, x);
    else if (x > n.val) n.right = remove(n.right, x);
    else {
        if (!n.left) return n.right;             // 0 or 1 child
        if (!n.right) return n.left;
        let s = n.right;                         // 2 children:
        while (s.left) s = s.left;               //   inorder successor
        n.val = s.val;
        n.right = remove(n.right, s.val);
    }
    return n;
}

05 The recursion patterns

Before coding, decide which way information flows.

⬆️

Return info up

Children report a value, the parent combines it (post-order). Height, size, diameter, balanced, max path sum, LCA.

⬇️

Pass info down

Carry state from the root as parameters (pre-order). Path sum, valid BST bounds, max on the path (“good nodes”), depth.

↔️

Both at once

Return one thing while updating a global answer: diameter returns height but records left + right at every node.

🌊

Level by level

Right side view, zigzag, averages, minimum depth: BFS with the queue-size trick.

📏

Use the BST order

Kth smallest, validate, LCA in a BST, range sum: go left or right instead of searching both sides — or use inorder = sorted.

🏗️

Build from traversals

Preorder gives the root; inorder splits left from right. Serialize with preorder + null markers.

Pass info down — validate a BST with bounds

bool valid(TreeNode* n, long long lo, long long hi) {
    if (!n) return true;
    if (n->val <= lo || n->val >= hi) return false;
    return valid(n->left, lo, n->val) &&      // left: tighten the upper bound
           valid(n->right, n->val, hi);       // right: tighten the lower bound
}
// valid(root, LLONG_MIN, LLONG_MAX)
boolean valid(TreeNode n, long lo, long hi) {
    if (n == null) return true;

           valid(n.right, n.val, hi);         // right: tighten the lower bound
}
// valid(root, Long.MIN_VALUE, Long.MAX_VALUE)
function valid(n, lo = -Infinity, hi = Infinity) {

           valid(n.right, n.val, hi);         // right: tighten the lower bound
}

Both at once — diameter

int best = 0;
int depth(TreeNode* n) {                 // returns height...
    if (!n) return 0;
    int l = depth(n->left), r = depth(n->right);
    best = max(best, l + r);             // ...while recording the answer
    return 1 + max(l, r);
}
int best = 0;
int depth(TreeNode n) {                  // returns height...
    if (n == null) return 0;
    int l = depth(n.left), r = depth(n.right);
    best = Math.max(best, l + r);        // ...while recording the answer
    return 1 + Math.max(l, r);
}

function depth(n) {                      // returns height...
    if (!n) return 0;
    const l = depth(n.left), r = depth(n.right);
    best = Math.max(best, l + r);        // ...while recording the answer
    return 1 + Math.max(l, r);
}

06 Tips & tricks to learn it properly

🙈

Trust the recursion

Assume the call on a child returns the right answer for that subtree. Only think about combining at the current node.

🪹

Base case first

Start every function with “if node is null, return …”. Choosing that value (0, true, −∞, null) is half the solution.

✏️

Draw 3–7 nodes

Sketch a small tree, including a lopsided one, and trace your function by hand before running it.

🔤

Remember the orders

The name says where the node goes: pre = first, in = in the middle, post = last.

📈

BST + inorder = sorted

Whenever a BST problem mentions order, k-th, or “closest”, think inorder traversal.

⚠️

Validate with bounds

Checking only left < node < right locally is wrong — a deep node can violate an ancestor. Pass (lo, hi) down.

🌳

Height can be n

Recursion depth equals tree height. A skewed tree of 10⁵ nodes can overflow the stack — mention iterative BFS/DFS.

🌐

Global vs returned values

If the answer isn’t what the parent needs (diameter, max path sum), return one thing and update a global/field for the answer.

🔁

Same tree, two trees

Symmetric, same tree, subtree: recurse on pairs of nodes f(a, b).

🧮

Count carefully

Height in nodes vs edges, depth from 0 or 1 — state your convention out loud.

🧭

BFS for “nearest”

Minimum depth, closest leaf, right side view: BFS finds them level by level and can stop early.

📦

Return pairs

Need two facts from a child (height and balanced? robbed/not robbed?) — return a pair or array.

Common mistakes checklist

  • Forgetting the null base case → null-pointer errors.
  • Validating a BST by comparing only parent and children.
  • Using int bounds (INT_MIN) when node values can equal them.
  • Mixing up height measured in nodes vs edges.
  • Recomputing heights at every node → O(n²) (balanced tree check).
  • In BFS, not snapshotting the queue size → levels mix together.
  • Comparing node values instead of node identity in LCA.

A 10-day practice plan

  1. Day 1: all four traversals (recursive + iterative inorder).
  2. Day 2: max depth, invert, same tree, symmetric tree.
  3. Day 3: path sum, balanced tree, diameter.
  4. Day 4: level order, zigzag, right side view.
  5. Day 5: BST search/insert/delete; validate BST.
  6. Day 6: kth smallest, LCA in a BST.
  7. Day 7: LCA in a binary tree, count good nodes.
  8. Day 8: construct from preorder + inorder.
  9. Day 9: max path sum, binary tree cameras.
  10. Day 10: serialize/deserialize; redo mistakes.
