Stacks & Queues

Two of the simplest data structures — and two of the most useful. A stack remembers what you need to come back to; a queue processes things in the order they arrived. Learn when to reach for each, and the monotonic tricks that turn O(n²) problems into O(n).

01 The basics

Stack — Last In, First Out

Like a pile of plates: you add to the top and take from the top. The last thing pushed is the first thing popped.

  • push(x) — put x on top · O(1)
  • pop() — remove the top · O(1)
  • peek()/top() — look at the top without removing · O(1)

Used for: undo/redo, the function call stack, browser “back”, matching brackets, DFS, expression evaluation.

Queue — First In, First Out

Like a line at a ticket counter: join at the back, leave from the front. The first thing in is the first thing out.

  • enqueue(x)/offer(x) — add at the back · O(1)
  • dequeue()/poll() — remove from the front · O(1)
  • front()/peek() — look at the front · O(1)

Used for: BFS, task scheduling, printer jobs, message buffers, rate limiting, streaming data.

02 Stacks & queues in code

Use the library in interviews — but know how to build them, because “implement X using Y” questions are common.

Built-in stack

#include <stack>
stack<int> st;
st.push(1); st.push(2);
int top = st.top();     // 2  (top() reads, pop() returns void!)
st.pop();
bool empty = st.empty();
// vector<int> with push_back / back / pop_back works too
import java.util.ArrayDeque;
import java.util.Deque;
Deque<Integer> st = new ArrayDeque<>();   // prefer over legacy Stack class
st.push(1); st.push(2);
int top = st.peek();    // 2
st.pop();               // returns 2
boolean empty = st.isEmpty();
const st = [];          // a plain array is a perfect stack
st.push(1); st.push(2);
const top = st[st.length - 1];   // 2  (or st.at(-1))
st.pop();               // returns 2, O(1)
const empty = st.length === 0;

Built-in queue / deque

#include <queue>
queue<int> q;
q.push(1); q.push(2);
int front = q.front();  // 1
q.pop();

deque<int> dq;          // both ends: push_front/back, pop_front/back
dq.push_back(3); dq.push_front(0);
Queue<Integer> q = new ArrayDeque<>();
q.offer(1); q.offer(2);
int front = q.peek();   // 1
q.poll();               // returns 1 (null if empty)

Deque<Integer> dq = new ArrayDeque<>();
dq.offerLast(3); dq.offerFirst(0);   // also pollFirst/pollLast
// JS has no built-in queue. array.shift() is O(n) — it moves every element!
// For BFS-style loops, keep a head index instead:
const q = [1, 2];
let head = 0;
while (head < q.length) {
    const x = q[head++];      // O(1) dequeue
    // ... q.push(next) to enqueue
}
// Need a reusable queue? See the circular queue below.

Implement a stack with an array

class ArrayStack {
    vector<int> a;
public:
    void push(int x) { a.push_back(x); }
    int pop() { int x = a.back(); a.pop_back(); return x; }
    int peek() { return a.back(); }
    bool empty() { return a.empty(); }
};
class ArrayStack {
    private int[] a = new int[8];
    private int size = 0;
    void push(int x) {
        if (size == a.length) a = Arrays.copyOf(a, size * 2);   // grow
        a[size++] = x;
    }
    int pop() { return a[--size]; }
    int peek() { return a[size - 1]; }
    boolean isEmpty() { return size == 0; }
}
class ArrayStack {
    constructor() { this.a = []; }
    push(x) { this.a.push(x); }
    pop() { return this.a.pop(); }
    peek() { return this.a[this.a.length - 1]; }
    isEmpty() { return this.a.length === 0; }
}

Circular queue (ring buffer)

A fixed array plus a head index and a size. The tail position is (head + size) % cap — indices wrap around instead of shifting elements.

class RingQueue {
    vector<int> a; int head = 0, size = 0;
public:
    RingQueue(int cap) : a(cap) {}
    bool enqueue(int x) {
        if (size == a.size()) return false;          // full
        a[(head + size) % a.size()] = x; size++;
        return true;
    }
    int dequeue() {                                  // assumes not empty
        int x = a[head];
        head = (head + 1) % a.size(); size--;
        return x;
    }
};
class RingQueue {
    private final int[] a; private int head = 0, size = 0;
    RingQueue(int cap) { a = new int[cap]; }
    boolean enqueue(int x) {
        if (size == a.length) return false;          // full
        a[(head + size) % a.length] = x; size++;
        return true;
    }
    int dequeue() {                                  // assumes not empty
        int x = a[head];
        head = (head + 1) % a.length; size--;
        return x;
    }
}
class RingQueue {
    constructor(cap) { this.a = new Array(cap); this.head = 0; this.size = 0; }
    enqueue(x) {
        if (this.size === this.a.length) return false;   // full
        this.a[(this.head + this.size) % this.a.length] = x;
        this.size++;
        return true;
    }
    dequeue() {                                         // assumes not empty
        const x = this.a[this.head];
        this.head = (this.head + 1) % this.a.length;
        this.size--;
        return x;
    }
}

04 The patterns that matter

Almost every stack/queue interview question is one of these.

1 · Matching pairs

Push openers; on a closer, the top must be its partner. Also: remove adjacent duplicates, backspace strings, decode string.

bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(') st.push(')');
        else if (c == '[') st.push(']');
        else if (c == '{') st.push('}');
        else if (st.empty() || st.top() != c) return false;
        else st.pop();
    }
    return st.empty();
}
boolean isValid(String s) {
    Deque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') st.push(')');
        else if (c == '[') st.push(']');
        else if (c == '{') st.push('}');
        else if (st.isEmpty() || st.pop() != c) return false;
    }
    return st.isEmpty();
}
function isValid(s) {
    const pair = { "(": ")", "[": "]", "{": "}" };
    const st = [];
    for (const c of s) {
        if (pair[c]) st.push(pair[c]);       // push the expected closer
        else if (st.pop() !== c) return false;
    }
    return st.length === 0;
}

2 · Monotonic stack

Keep the stack sorted (e.g. decreasing). When a new element breaks the order, everything you pop has just found its next greater element. Daily temperatures, stock span, histogram, trapping rain water.

vector<int> nextGreater(vector<int>& a) {
    vector<int> res(a.size(), -1);
    stack<int> st;                       // indices, values decreasing
    for (int i = 0; i < a.size(); i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            res[st.top()] = a[i];
            st.pop();
        }
        st.push(i);
    }
    return res;
}
int[] nextGreater(int[] a) {
    int[] res = new int[a.length];
    Arrays.fill(res, -1);
    Deque<Integer> st = new ArrayDeque<>();   // indices, values decreasing
    for (int i = 0; i < a.length; i++) {
        while (!st.isEmpty() && a[st.peek()] < a[i])
            res[st.pop()] = a[i];
        st.push(i);
    }
    return res;
}
function nextGreater(a) {
    const res = new Array(a.length).fill(-1);
    const st = [];                        // indices, values decreasing
    for (let i = 0; i < a.length; i++) {
        while (st.length && a[st[st.length - 1]] < a[i])
            res[st.pop()] = a[i];
        st.push(i);
    }
    return res;
}

3 · Monotonic deque (sliding window)

Store indices with decreasing values. The front is always the window’s max; drop it when it slides out, drop smaller values from the back when a bigger one arrives.

deque<int> dq;                         // indices, values decreasing
for (int i = 0; i < n; i++) {
    if (!dq.empty() && dq.front() <= i - k) dq.pop_front();     // left the window
    while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();  // useless now
    dq.push_back(i);
    if (i >= k - 1) out.push_back(a[dq.front()]);
}
Deque<Integer> dq = new ArrayDeque<>(); // indices, values decreasing
for (int i = 0; i < n; i++) {
    if (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst();     // left the window
    while (!dq.isEmpty() && a[dq.peekLast()] <= a[i]) dq.pollLast();  // useless now
    dq.offerLast(i);
    if (i >= k - 1) out[i - k + 1] = a[dq.peekFirst()];
}
const dq = [];                         // indices, values decreasing
let head = 0;                          // front of the deque (avoid shift)
for (let i = 0; i < n; i++) {
    if (head < dq.length && dq[head] <= i - k) head++;               // left the window
    while (dq.length > head && a[dq[dq.length - 1]] <= a[i]) dq.pop(); // useless now
    dq.push(i);
    if (i >= k - 1) out.push(a[dq[head]]);
}

4 · BFS with a queue

A queue explores in layers: everything 1 step away, then 2 steps, … That’s why BFS finds shortest paths in unweighted graphs and grids.

queue<int> q;
q.push(start); seen[start] = true;
for (int steps = 0; !q.empty(); steps++) {
    for (int sz = q.size(); sz > 0; sz--) {      // one whole layer
        int u = q.front(); q.pop();
        for (int v : adj[u])
            if (!seen[v]) { seen[v] = true; q.push(v); }
    }
}
Queue<Integer> q = new ArrayDeque<>();
q.offer(start); seen[start] = true;
for (int steps = 0; !q.isEmpty(); steps++) {
    for (int sz = q.size(); sz > 0; sz--) {      // one whole layer
        int u = q.poll();
        for (int v : adj.get(u))
            if (!seen[v]) { seen[v] = true; q.offer(v); }
    }
}
let layer = [start];
seen[start] = true;
for (let steps = 0; layer.length; steps++) {
    const next = [];                             // one whole layer at a time
    for (const u of layer)
        for (const v of adj[u])
            if (!seen[v]) { seen[v] = true; next.push(v); }
    layer = next;
}
Two more tricks: a min stack stores the current minimum alongside each value, so getMin() is O(1); and a queue from two stacks pours the “in” stack into the “out” stack only when “out” is empty — every element moves at most once, so it’s amortised O(1).

05 Tips & tricks to learn it properly

🧭

Which one?

Need the most recent unfinished thing? Stack. Need things in arrival order or layer by layer? Queue.

🔗

“Nearest” means stack

“Next greater”, “previous smaller”, “nearest wall” → monotonic stack, O(n) instead of O(n²).

🪟

Window max/min means deque

Sliding window maximum or minimum → monotonic deque of indices. Each index enters and leaves once.

📍

Store indices, not values

Indices give you both the value (a[i]) and the distance (i − j) — needed for spans, widths and windows.

🛑

Check empty before pop

Popping or peeking an empty stack is the #1 runtime error. In C++ it’s undefined behaviour, not an exception.

🐢

Don’t shift() in JS

array.shift() is O(n). Use a head index, a ring buffer, or swap whole layers in BFS.

☕

Java: use ArrayDeque

The old Stack class is synchronised and slow. ArrayDeque is the modern stack and queue.

🔁

Recursion is a stack

Any recursive DFS can be rewritten with an explicit stack — handy when recursion depth would overflow.

🧮

Expressions → stacks

Postfix (RPN) evaluation needs one stack. Infix with brackets: push the running result and sign when you see “(”.

♻️

Ring buffer for fixed size

(head + size) % cap is the tail. Track size to tell “full” from “empty”.

➕

Augment the stack

Store pairs like (value, min so far) or (price, span) to answer extra queries in O(1).

✏️

Trace the stack on paper

Write the stack contents after each step for a small input. Monotonic-stack bugs become obvious.

Common mistakes checklist

  • Popping/peeking an empty stack or queue.
  • Forgetting to check the stack is empty at the end (unclosed brackets).
  • In C++, expecting st.pop() to return the value (it returns void).
  • Using array.shift() in a JS BFS loop → O(n²).
  • Comparing with < vs <= wrong in a monotonic stack (duplicates!).
  • Pushing values when you later need indices (widths, spans).
  • Ring buffer can’t tell full from empty because size isn’t tracked.
