Linked Lists

A chain of nodes, each pointing to the next. There’s no indexing and no contiguous memory — just pointers. Learn to draw the boxes and arrows, master four techniques (dummy node, fast/slow pointers, in-place reversal, merging) and almost every linked list question becomes routine.

01 The basics

What is a linked list?

A linked list is a sequence of nodes. Each node stores a value and a pointer (reference) to the next node. The list is accessed through its head; the last node points to null.

head→ 7next→ 3next→ 9next→ null
  • Nodes can live anywhere in memory — the pointers hold the order.
  • To reach the k-th node you must walk k steps from the head: O(n).
  • Inserting or deleting at a known node is just re-pointing: O(1).

Kinds of linked lists

  • Singly linked: each node has next. Most interview questions use this.
  • Doubly linked: prev and next. O(1) delete of a given node; used in LRU caches, std::list, Java LinkedList.
  • Circular: the tail points back to the head. Used for round-robin scheduling and the Josephus problem.
null⇄ prev1next⇄ prev2next⇄ null

The node

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* head = new ListNode(7);
head->next = new ListNode(3);
head->next->next = new ListNode(9);   // 7 -> 3 -> 9 -> null
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}

ListNode head = new ListNode(7);
head.next = new ListNode(3);
head.next.next = new ListNode(9);    // 7 -> 3 -> 9 -> null
class ListNode {
    constructor(val = 0, next = null) {
        this.val = val;
        this.next = next;
    }
}

const head = new ListNode(7, new ListNode(3, new ListNode(9)));   // 7 -> 3 -> 9 -> null

02 Core operations

Write each of these from memory. The golden rule: connect the new pointer before you break the old one.

Traverse, length & search

int length(ListNode* head) {
    int n = 0;
    for (ListNode* cur = head; cur; cur = cur->next) n++;
    return n;
}
ListNode* find(ListNode* head, int x) {
    ListNode* cur = head;
    while (cur && cur->val != x) cur = cur->next;
    return cur;                       // nullptr if not found
}
int length(ListNode head) {
    int n = 0;
    for (ListNode cur = head; cur != null; cur = cur.next) n++;
    return n;
}
ListNode find(ListNode head, int x) {
    ListNode cur = head;
    while (cur != null && cur.val != x) cur = cur.next;
    return cur;                       // null if not found
}
function length(head) {
    let n = 0;
    for (let cur = head; cur; cur = cur.next) n++;
    return n;
}
function find(head, x) {
    let cur = head;
    while (cur && cur.val !== x) cur = cur.next;
    return cur;                       // null if not found
}

Insert at head / after a node

ListNode* pushFront(ListNode* head, int x) {
    ListNode* node = new ListNode(x);
    node->next = head;                // 1. connect new
    return node;                      // 2. new head
}
void insertAfter(ListNode* prev, int x) {
    ListNode* node = new ListNode(x);
    node->next = prev->next;          // 1. connect new first
    prev->next = node;                // 2. then break old link
}

Insert at tail

Without a tail pointer you must walk to the last node. Handle the empty list separately (or use a dummy node).

ListNode* pushBack(ListNode* head, int x) {
    ListNode* node = new ListNode(x);
    if (!head) return node;
    ListNode* cur = head;
    while (cur->next) cur = cur->next;
    cur->next = node;
    return head;
}
ListNode pushBack(ListNode head, int x) {
    ListNode node = new ListNode(x);
    if (head == null) return node;
    ListNode cur = head;
    while (cur.next != null) cur = cur.next;
    cur.next = node;
    return head;
}
function pushBack(head, x) {
    const node = new ListNode(x);
    if (!head) return node;
    let cur = head;
    while (cur.next) cur = cur.next;
    cur.next = node;
    return head;
}

Delete by value (with a dummy node)

A dummy node before the head means deleting the head is no longer a special case.

ListNode* removeValue(ListNode* head, int x) {
    ListNode dummy(0);
    dummy.next = head;
    ListNode* prev = &dummy;
    while (prev->next && prev->next->val != x) prev = prev->next;
    if (prev->next) {
        ListNode* del = prev->next;
        prev->next = del->next;       // bypass the node
        delete del;
    }
    return dummy.next;
}
ListNode removeValue(ListNode head, int x) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode prev = dummy;
    while (prev.next != null && prev.next.val != x) prev = prev.next;
    if (prev.next != null) prev.next = prev.next.next;   // bypass
    return dummy.next;
}
function removeValue(head, x) {
    const dummy = new ListNode(0, head);
    let prev = dummy;
    while (prev.next && prev.next.val !== x) prev = prev.next;
    if (prev.next) prev.next = prev.next.next;   // bypass
    return dummy.next;
}

    04 The four techniques

    Nearly every linked list question is one of these, or two of them combined.

    1 · Dummy (sentinel) node

    Create a fake node in front of the head whenever the head itself might change (deleting, merging, building a new list). Return dummy.next at the end — no special cases for the first node.

    ListNode dummy(0);
ListNode* tail = &dummy;
// ... tail->next = someNode; tail = tail->next; ...
return dummy.next;
    ListNode dummy = new ListNode(0);
ListNode tail = dummy;
// ... tail.next = someNode; tail = tail.next; ...
return dummy.next;
    const dummy = new ListNode(0);
let tail = dummy;
// ... tail.next = someNode; tail = tail.next; ...
return dummy.next;

    2 · Fast & slow pointers

    slow moves 1 step, fast moves 2. When fast reaches the end, slow is at the middle. If there’s a cycle, fast eventually laps slow and they meet (Floyd’s algorithm).

    ListNode *slow = head, *fast = head;
while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;
    if (slow == fast) { /* cycle! */ }
}
// no cycle: slow is the middle (2nd middle for even length)
    ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow == fast) { /* cycle! */ }
}
// no cycle: slow is the middle (2nd middle for even length)
    let slow = head, fast = head;
while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) { /* cycle! */ }
}
// no cycle: slow is the middle (2nd middle for even length)

    3 · In-place reversal

    Three pointers: prev, curr, next. Save next, flip the arrow, move both forward. Memorise it — it shows up inside palindrome, reorder list, k-group reversal and more.

    ListNode* reverse(ListNode* head) {
    ListNode *prev = nullptr, *curr = head;
    while (curr) {
        ListNode* next = curr->next;  // 1. save
        curr->next = prev;            // 2. flip
        prev = curr;                  // 3. advance
        curr = next;
    }
    return prev;                      // new head
}
    ListNode reverse(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;    // 1. save
        curr.next = prev;             // 2. flip
        prev = curr;                  // 3. advance
        curr = next;
    }
    return prev;                      // new head
}
    function reverse(head) {
    let prev = null, curr = head;
    while (curr) {
        const next = curr.next;       // 1. save
        curr.next = prev;             // 2. flip
        prev = curr;                  // 3. advance
        curr = next;
    }
    return prev;                      // new head
}

    4 · Merging two sorted lists

    Dummy node + a tail pointer. Always attach the smaller head, then append whatever is left. Building block for merge sort and merge k lists.

    ListNode* merge(ListNode* a, ListNode* b) {
    ListNode dummy(0), *tail = &dummy;
    while (a && b) {
        if (a->val <= b->val) { tail->next = a; a = a->next; }
        else                  { tail->next = b; b = b->next; }
        tail = tail->next;
    }
    tail->next = a ? a : b;
    return dummy.next;
}
    ListNode merge(ListNode a, ListNode b) {
    ListNode dummy = new ListNode(0), tail = dummy;
    while (a != null && b != null) {
        if (a.val <= b.val) { tail.next = a; a = a.next; }
        else                { tail.next = b; b = b.next; }
        tail = tail.next;
    }
    tail.next = (a != null) ? a : b;
    return dummy.next;
}
    function merge(a, b) {
    const dummy = new ListNode(0);
    let tail = dummy;
    while (a && b) {
        if (a.val <= b.val) { tail.next = a; a = a.next; }
        else                { tail.next = b; b = b.next; }
        tail = tail.next;
    }
    tail.next = a || b;
    return dummy.next;
}
    Gap of k: a variant of two pointers. Move fast k steps ahead, then move both together. When fast hits the end, slow is k nodes from the end — the trick behind “remove n-th node from end” and “rotate list”.

    05 Tips & tricks to learn it properly

    ✏️

    Always draw it

    Boxes and arrows on paper. Cross out an arrow when you re-point it. Pointer bugs are obvious on a drawing, invisible in your head.

    🔗

    Connect before you cut

    Set node.next = prev.next before prev.next = node. Lose the only reference and the rest of the list is gone.

    🪆

    Use a dummy node

    Whenever the head might change. It removes the “if head is null / if deleting head” branches.

    🛑

    Guard every .next

    Before p.next.next, make sure p and p.next exist. while (fast && fast.next) is the classic guard.

    🐢

    Fast/slow for “middle” and “cycle”

    Any question about the middle, a cycle, or the k-th from the end → two pointers, O(1) space.

    🔁

    Reversal is a building block

    Palindrome = find middle + reverse second half + compare. Reorder list = middle + reverse + merge.

    🧪

    Test the edge lists

    Empty list, one node, two nodes, and odd vs even length. Most crashes come from the 0/1/2-node cases.

    📍

    Name your pointers

    prev / curr / nxt, slow / fast, tail. Clear names make the update order easy to reason about.

    🗺️

    HashMap for extra links

    Random pointers, intersection, cycle start — a map/set from node → info is the easy O(n)-space solution. Then optimise.

    ♻️

    Recursion mirrors the list

    “Solve for head.next, then fix up head.” Great for reverse and merge — but uses O(n) stack.

    🧹

    Free memory in C++

    When deleting a node in C++, delete it after unlinking. Java and JavaScript garbage-collect it for you.

    🗣️

    Say the invariant

    e.g. “everything before curr is already reversed and starts at prev”. Interviewers love it.

    Common mistakes checklist

    • Losing the rest of the list by overwriting next before saving it.
    • Dereferencing null — not checking curr / curr.next.
    • Forgetting to return the new head after reversal or deleting the head.
    • Moving the head pointer itself while traversing (use a separate cur).
    • Forgetting to set the new tail’s next = null → accidental cycle.
    • Off-by-one when counting k steps for the k-th node from the end.
    • Comparing node values when you should compare node identity (intersection, cycle).

    A 10-day practice plan

    1. Day 1: build a list, traverse, insert/delete at head, tail and index.
    2. Day 2: reverse (iterative + recursive), remove elements, remove duplicates.
    3. Day 3: middle of list, cycle detection, cycle start.
    4. Day 4: merge two sorted lists, intersection of two lists.
    5. Day 5: remove n-th from end, palindrome list.
    6. Day 6: add two numbers, odd-even list, rotate list.
    7. Day 7: reorder list, reverse between m and n.
    8. Day 8: copy list with random pointer, sort list (merge sort).
    9. Day 9: LRU cache (doubly linked list + hash map).
    10. Day 10: reverse k-group, merge k sorted lists; redo your mistakes.
